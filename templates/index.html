FREQUENTLY ASKED QUESTIONS

Answers for Legal Administrators & Citizens

How does executive approval for Judicial Officers operate?
Judge and Registrar registrations automatically enter pending_gov status. The Government Administration reviews submitted service credentials, employee IDs, and Bar records before granting active judicial bench access.
Are digital orders issued on NyayaDesk legally tamper-evident?
Yes. Each order and judgment generates a cryptographic SHA-256 hash linking the order content, issuing judge ID, and timestamp, alongside a verification code (e.g. NYAYA-ORD-0010-2026) verifiable at /orders/verify/<code>.
How does the hearing collision detection engine work?
When scheduling a hearing, the system inspects whether the designated judge or courtroom is booked within 30 minutes. If a collision is found, the scheduler rejects the slot with HTTP 409 and presents AI-recommended vacant alternative slots.
Does NyayaDesk require internet or cloud API keys to operate?
No. NyayaDesk features a dual-mode engine: it defaults to an offline rule-based legal synthesis engine that operates seamlessly without external API keys or internet access. When a GEMINI_API_KEY is configured, it transitions to live Gemini 1.5.
