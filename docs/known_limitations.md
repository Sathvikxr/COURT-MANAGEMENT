# NyayaDesk: Known Limitations & Operational Constraints

This document provides a candid, engineering-first disclosure of the known architectural boundaries, environmental dependencies, and operational trade-offs present in **NyayaDesk**.

---

## 1. System Dependencies & Environment Requirements

### 1.1 Tesseract OCR Dependency for Scanned Document Intelligence
- **Condition:** Feature 3 (Smart Document Intelligence & OCR Auto-Fill) uses `pytesseract` to extract party names, statutory sections, and claim values from scanned image petitions and raster PDFs.
- **Limitation:** `pytesseract` is a Python wrapper requiring the native Tesseract binary (`tesseract.exe`) to be installed on the host operating system and accessible via the system `PATH`.
- **Mitigation / Fallback:** If Tesseract is not installed on the server, the system gracefully degrades to a simulated text heuristic extractor. While this prevents application crashes and allows testing, real optical character recognition of non-text PDFs requires installing the native Tesseract OCR engine (`v5.3+`).

### 1.2 Audio Transcription & Local Whisper Constraints
- **Condition:** Feature 5 (Hearing Audio Transcription & Minutes) processes court audio recordings and microphone streams.
- **Limitation:** Running high-accuracy local Whisper models (e.g. `faster-whisper` large-v3) requires GPU hardware (CUDA), `ffmpeg` system binaries, and substantial RAM (>4GB). On resource-constrained or Windows developer machines without CUDA/ffmpeg, audio transcription defaults to either the cloud Gemini audio API (when `GEMINI_API_KEY` is present) or the offline benchmark transcript generator.
- **Mitigation:** Court deployments should configure dedicated transcription server sidecars or use authenticated cloud speech APIs with appropriate bandwidth.

### 1.3 Windows Application Control & SQLite C Extensions
- **Condition:** On Windows enterprise systems running AppLocker or Windows Defender Application Control (WDAC), precompiled C-extension DLLs (such as SQLAlchemy's `_collections_cy.pyd`) can be blocked when loaded from newly created virtual environment directories.
- **Mitigation:** The application explicitly sets `DISABLE_SQLALCHEMY_CEXT = '1'` in `app/__init__.py` and `run.py`. This ensures 100% portable pure-Python execution without performance degradation on modern Python 3.11+.

## 2. Artificial Intelligence & Legal Domain Boundaries

### 2.1 Synthetic Precedent Library vs. Real Law Reporting
- **Condition:** Feature 1 (Semantic Case-Law and Precedent Search) queries a seeded local vector index.
- **Limitation:** All 30 seeded precedents in `PrecedentLibrary` are 100% synthetic, fictional judicial authorities created strictly for software benchmarking, semantic vector search, and demonstration purposes.
- **Mandate:** NyayaDesk does NOT connect to real live law reporting services (e.g., SCC Online, Manupatra, or Indian Kanoon) out of the box. Judicial officers must never cite synthetic test precedents in real court orders.

### 2.2 Vernacular Machine Translation Accuracy (Article 348 Notice)
- **Condition:** Feature 6 translates orders, notices, and reminders between English, Telugu, and Hindi.
- **Limitation:** While the translation engine incorporates specialized legal dictionaries (e.g. *Vakalatnama*, *interim injunction*, *affidavit*), nuanced jurisdictional or archaic statutory terms may lose subtle legal semantics during machine translation.
- **Constitutional Boundary:** Under **Article 348 of the Constitution of India**, the English language is the sole authoritative legal record for superior courts. All translations generated by NyayaDesk are legally designated as machine-assisted indicative previews for litigant understanding and must never supersede the signed English original.

### 2.3 RAG Grounded Refusal Thresholds
- **Condition:** Feature 2 ("Ask the Case File" RAG) is strictly constrained to answer queries using the uploaded case docket and hearing history.
- **Behavior:** The assistant enforces a strict keyword and TF-IDF relevance threshold (`min_score = 2`). If a user asks questions regarding extraneous legal topics not present in that specific docket file (e.g., asking about corporate insolvency on a family dispute case), the model refuses to answer (*"Information not found in the case file"*). This is an intentional safety feature, but users expecting open-ended legal advice may find the refusal restrictive.

## 3. Database Architecture & Scalability

### 3.1 SQLite Single-Writer Lock Contention
- **Condition:** NyayaDesk defaults to a local SQLite database (`data/court.db`) for zero-configuration, single-command startup.
- **Limitation:** SQLite allows multiple concurrent readers but serializes writes via database-level locking. Under heavy enterprise concurrency (e.g., >100 simultaneous clerks and judges submitting hearings, orders, and registrations within the same second), write latency may increase due to SQLite busy retries.
- **Enterprise Upgrade:** For statewide or national deployments, the `SQLALCHEMY_DATABASE_URI` should be switched to PostgreSQL (`postgresql+psycopg2://...`) with connection pooling enabled.

### 3.2 File Storage & Direct Disk Uploads
- **Condition:** Uploaded case petitions and identity proofs are saved to the local filesystem at `uploads/cases/` and `uploads/id_proofs/`.
- **Limitation:** In multi-instance or clustered load-balanced deployments (e.g. Kubernetes with multiple replicas), local filesystem storage cannot be shared across nodes without a distributed shared volume (NFS) or an S3-compatible object storage gateway (e.g. AWS S3, MinIO).

## 4. Browser & Automation Testing

### 4.1 Playwright E2E Tests & Sandbox Network Isolation
- **Condition:** End-to-end browser automation (`tests/test_e2e_playwright.py`) and accessibility scans (`tests/test_accessibility.py`) launch a headless Chromium browser.
- **Limitation:** Playwright requires an external Chromium process that communicates with Python via loopback TCP sockets. Inside strict container sandboxes with network loopback isolation, Playwright tests must be executed with appropriate local socket permissions or outside the sandbox.
